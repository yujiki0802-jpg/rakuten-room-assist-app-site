PERSONAL CHROME EXTENSION

楽天ROOM
準備アシスト

楽天市場の商品リサーチから、紹介文の作成、ROOM投稿直前の入力までを支援する個人用Chrome拡張機能です。

開発・個人利用中

ASSIST FLOW

  1. 01市場データを取得
  2. 02条件に合う商品を選定
  3. 03紹介文を生成
  4. 04本人確認後に投稿

01

PURPOSE & FEATURES

利用目的と主な機能

◎

商品リサーチ

楽天Web Serviceを利用し、ランキング順位、検索順位、レビュー評価・件数、画像、販売中かどうかなどの商品情報を取得します。

◇

候補の整理

評価4.0以上かつレビュー100件以上の商品を基本条件とし、投稿候補を最大30件のキューに整理します。

✦

紹介文作成

取得した商品情報を基に、価格や送料、未確認の商品体験を含めない短い紹介文の作成を補助します。

✓

本人による最終確認

商品画像と紹介文を確認できる状態まで準備します。ROOMの最終投稿操作は自動化せず、利用者本人が行います。

02

DATA USAGE

APIデータの利用方法

取得した情報は、個人用の商品調査、投稿候補の比較、ROOM投稿準備のためにのみ使用します。

  • 楽天市場の商品名・説明・画像・URL
  • ランキング順位または検索表示順位
  • レビュー平均・レビュー件数
  • 販売状態および商品に付随する公開情報

IMPORTANT

取得データの再販売や第三者向けデータベースの提供は行いません。楽天のサービスを装うものではなく、楽天グループ各社が提供・運営する公式アプリではありません。

03

PRIVACY & SECURITY

プライバシーと保存

保存場所

投稿キュー、履歴、API設定は、利用者のChromeプロファイル内にある拡張機能ローカル領域へ保存します。

外部送信

楽天Web Serviceの認証情報は楽天APIへ、文章生成用APIキーと商品情報はGoogle Gemini APIへ、それぞれ必要な処理のために送信します。

このWebサイト

この説明サイトには、入力フォーム、アクセス解析、広告、Cookie、利用者データの収集機能はありません。

認証情報

Application ID、Access Key、Gemini APIキーをこの説明サイトに掲載したり、サイト側へ保存したりすることはありません。
